# proofgraph/outerwall — the outer wall (the OUTERWALL-CONTRACT face)

The package behind `analyze` / `analyze_session` / `system_pins`
(`OUTERWALL-CONTRACT.md` at the repo root is the frozen contract):
`analyze_run` sequences the whole composition — the hub pipeline with the
real V1 capability feed (shutdown in a `finally`, pins snapshot taken
first), declared-root resolution (never guessed), ruling-8 outline fill
with a rustworkx-vs-networkx closure crosscheck, re-ingest of the filled
graph through the model wall, canonical-schema validation, and gap +
provenance assembly with build-failing hole checks — and `system_pins` is
the outermost diagnostic surface aggregating the five probe catalogs
(422 entries measured on MOAT). Consumers: `hub/server_analyze.py`, the
acceptance runners, and both suites. Suites (re-run after this round's doc
fixes, counts unchanged): `python outerwall/test_outerwall.py` = 41 tests ·
`python outerwall/test_real_inputs.py` = 21 tests.
(`audit/AUDIT-outerwall.json`, 2026-08-03)
