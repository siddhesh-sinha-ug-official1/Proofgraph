# app/src — the UI-1C shell source

The graph-first shell as assembly code over cell walls: the `App` facade and
its hooks (state composition, data pipeline, UI state, analyze/save flows,
file flows, pure derivations), the chrome components (header, menubar, rail,
status bar, welcome, explorer, search-everywhere, dialogs, settings), the
tool-window layer over the pure layout2 model/geometry/machine/persistence,
the lazy editor pane gluing cell 4's Monaco wall, the feeding tubes
(`graphSource*` three-way byte gate, `analysisSource` verdict overlay,
`fsSource*` workspace-fs endpoints), the V5 joined-bus adapter
(`busAdapter*`), prefs/recents persistence, the shell probe log, the pure
tab store and uri helpers. `css/` files are tabled in `css/README.md`
(`styles.css`, the entry sheet carrying the cell-5 DOM skin section, stays
here).
