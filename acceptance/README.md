# proofgraph/acceptance — the §7 acceptance gate

Two one-command facades, both invoked by `run_all_suites.py`:
`python acceptance/run_demo.py` (step-1 analyze over the three fixtures,
the ten named checks a–j plus the default headless UI step; 11 PASS /
0 FAIL / 0 SKIP measured 2026-08-03) and
`python acceptance/run_shell_demo.py` (the app-shell contract loop over an
ephemeral hub on a temp fixture copy). Check families:
`checks/` (run_demo's — see `checks/README.md`), `shellchecks/`
(run_shell_demo's — see `shellchecks/README.md`), `headless/` (the
browser/node drivers — see `headless/README.md`).

Exempt from the file tables (fixture/generated, honored by
`audit/AUDIT-acceptance.json`): `fixtures/` (sha-pinned demo fixtures +
vendored real inputs), `evidence/` (regenerated every run),
`browser/*.png` (manual screenshots), `analysis-*.json` + `TRACE-full.json`
(written by the runner), `ACCEPTANCE-REPORT.md` (regenerated by
`checks/reporting.py` every run).
