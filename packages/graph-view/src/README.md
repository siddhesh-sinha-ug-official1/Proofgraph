# graph-view/src

All cell source plus its vitest gates in one flat directory: the S0-S7 pipeline (`ingest*`, `cap`, `verdict`, `layoutIn`, `layout*`, `apply`, `renderGate*`, `cell`, `link*`), the React Flow DOM half (`GraphView.tsx`, `ProofNode.tsx`, `LeadEdge.tsx`), the probe bus and catalog sections, the Phase-1 wall (`wall.ts`, `wallTypes.ts`), the Tree-4 event-bus seam (`eventBus.ts`), test substrate (`domShims.ts`, `wallTestKit.ts`, `testUtil.ts`), and the `*.test.*` suites.
