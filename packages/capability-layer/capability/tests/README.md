# capability-layer/capability/tests

The 17-gate pytest suite - 131 tests including the live pyright (gate 16) and lean (gates 17/17b) batteries: import boundary, P2 litmus in both directions, honest ceiling, framing/encoding connectors, stage determinism, paper-vs-measured, P9 optionality, compiler-as-oracle parity, lifecycle, no-silent-caps, catalog, reproducibility, schema sync, the walking skeleton, and wall conformance/driven runs. `common.py`, `lean_common.py` and `wall_common.py` are the shared harnesses.
