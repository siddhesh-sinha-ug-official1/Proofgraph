# capability-layer/capability

The A-J measurement pipeline. `capability.py` runs the stages in code order (A discovery, B gate, C score, D tree-walk, E shim plan, F floor, G SCIP, the optional prepare step, I spine wire, H inventory, J probe battery) and stamps the measured tier into a Capability; `probes*.py` carry the bus and the 89-entry catalog split; `spine*.py` the LSP client; `probe_*.py` the P0-P11 battery; `schema.py` the equality-gated frozen-schema constants; `importgate.py` the import-boundary gate; `handle.py` the membrane object handed to Tree 3.
