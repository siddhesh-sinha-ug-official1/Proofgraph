# ProofGraph — Tree 4: Editor Shell (Monaco, JetBrains-grade)

The **text projection** of the ProofGraph model: an editor cell that renders live
diagnostics, each node's **FILL** verdict (its own compiler verdict) in the gutter,
its **OUTLINE** trust-base ring (worst-case-wins), and does **brushing-and-linking**
over a shared event bus carrying `Node.id`s — instrumented at **maximum probe
density** (the deliberately probe-able cell; since ASSEMBLY Phase 1 its minimal
membrane exists as `src/wall.ts` — `createEditorWall`, promoted OVER the pins,
never replacing them).

Two invariants this cell exists to guarantee:

1. **Green may never be faked.** A gutter glyph renders green only from a real
   compiler verdict (`fill.status green` + non-empty `fill.source` + provenance
   present with `resolved: true`) AND server tier `CT`. `unknown ≠ green`;
   blocked greens fire `editor.verdict.green.blocked` loudly.
2. **No silent rewrite.** The buffer never changes bytes (whitespace/EOL/
   encoding/BOM) without a user or API cause; violations fire
   `editor.buffer.mutation.silent` and fail the roundtrip gate.

## Introspection (Probe Density Contract)

`EditorShellCell` exposes `probeCatalog()` (every lead: id/kind/payloadType/
description/firehose), `dump()` (entire internal state), `tap(probeId, cb)`
(live lead subscription, `"*"` for all), `history()` (deterministically ordered
stream; `logicalClock` is the only ordering key, `wallNanos` never). Emitting an
uncataloged probeId throws — catalog and reality cannot drift.
