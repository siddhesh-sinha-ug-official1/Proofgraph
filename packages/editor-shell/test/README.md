# editor-shell/test

The 96-test node suite (31 files; built to dist/ and run via `scripts/run-tests.mjs`), one file per attack surface: silent rewrites, span math, brushing, the green guard, outline policy, the version guard, latency, LSP messages in both directions, the import gate, determinism, symbol reconciliation, hover, index stability, origin styling, provenance, reconnect, same-span conflicts, editor-agnosticism, catalog coverage/invariants, review regressions, schema sync, and wall conformance/teardown. `AGENT-GUIDE.md` is the historical build-round guide with a dated currency note.
