# structure-extractor/selftest

The 140-test unittest suite (`python selftest/run_all.py`; `--fast` filters live-pyright cases): boundary, connectors, goldens, honest ceiling, the lean CT dock/guards/decl-match gates, the live pyright oracle, probe bus, provenance, schema rulings and the membrane sync test, the walking skeleton, T1, T3, and the two wall suites. `harness.py` and the `*_common.py` files are shared substrate; `tools/gen_goldens.py` (folded into the table) regenerates the hand-reviewed goldens.
