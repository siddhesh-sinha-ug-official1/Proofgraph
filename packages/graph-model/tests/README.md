# graph-model/tests

The cell's 113-test unittest suite: canonical-schema sync gates, Appendix-B goldens, harness and catalog contracts, per-stage probe assertions, projection/roundtrip gates, reformat invariance, T3, and the three wall suites (conformance, rejections, standsup). `context.py` and `wall_testkit.py` are the shared bootstrap/helpers.
