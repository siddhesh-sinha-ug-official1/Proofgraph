# byok-arena/tests

The 103-test `node --test` gate suite: arena round-trip, catalog, cheap connectors, cost cliffs, determinism, the error matrix, gemini stale-cache regressions, the import boundary, secret leak scans, TRAP 1/2/3, usage mapping, validateKey, vault, and the two wall-conformance halves. `helpers.ts` and `wall-helpers.ts` are shared scaffolding.
